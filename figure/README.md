# Figures

This folder contains the main diagnostic and classification figures generated by the R workflow.

## Classification Error Curves

- `13067_CMS4_vs_Others.png`
- `13294_CMS4_vs_Others.png`
- `14333_CMS4_vs_Others.png`

These figures show classification error across progressively stronger TCGA–GEO batch separation settings (`50`, `70`, `80`, `90`, `100`) for multiple classifiers and normalization methods.

The strictest setting (`100`) corresponds to TCGA-only training and GEO-only testing.

## Before Alignment

The `before_alignment/` folder contains sample-level poor-marker expression boxplots before cross-platform alignment.

These plots visualize the initial distributional differences between the TCGA RNA-seq cohort and each GEO microarray cohort.

## After Alignment

The `after_alignment/` folder contains diagnostic feature-distribution boxplots after sample-wise rank-normal alignment.

These plots are used to verify that the most obvious differences in expression scale and spread are reduced before downstream classification.
